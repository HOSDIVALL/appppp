02 / 滚动不是外层自动赠送的

上面两个参数在RhythmAdaptiveModalSheet函数体中未使用。改变它们不会自动替内容加滚动条、渐隐或滚动能力。

helper也只是Box包装与绘制；调用方仍须提供实际可滚内容，并消费回传endPadding。本页用浏览器滚动条，不伪装成尚未完整核验的ExpressiveScrollBar。

代码而非注释
  • 尾部留白注释写32dp，实际target为12dp。
  • 渐隐默认高24，顶/底由能否向后/向前滚决定。
  • 多种state同时传入时是list优先、再grid、再scroll；false不会回退到下一个state。
  • Header的icon参数未绘制；subtitle仅isNotEmpty时显示，空白字符串仍非空。
Header / Action / Close

03 / 标题与控制按钮

关闭按钮36×36：圆角10→18；hover scale1.08，press .92；Close图标转90°并换error主题。Action有相同缩放/圆角，但没有图标旋转，禁用有独立配色。

36是视觉尺寸，不是已验证的Android可点击目标范围。标题源码为displayMedium；本页字号仅作Web阅读选择。手机分支只画默认拖动柄示意，没有伪造原生拖动关闭。

SwitchModeDialog.kt

04 / 确认只调onConfirm

源码的确认按钮只调用onConfirm，没有顺带onDismissRequest。两个全宽52dp按钮放在confirmButton区域，dismissButton为空。形状圆角24。

TrackCorruptionDialog.kt

05 / 先skip，后dismiss

onSkip(); onDismiss(); 是顺序调用，没有finally。若skip抛错，后续dismiss不会自动执行。本页仅用异常捕获器记录模拟结果，源组件没有这个catch。

PlaybackSpeedDialog.kt · 兼容适配器

06 / 名字叫Dialog，实际委托BottomSheet

这个文件不创建AlertDialog，而是调用PlaybackSpeedAndPitchBottomSheet。提供onSaveBoth时只调用它，否则onSave(speed)，不把pitch一起传出。本轮未读取被委托Sheet，故不模拟其滑块、保存后关闭或同步实现。
