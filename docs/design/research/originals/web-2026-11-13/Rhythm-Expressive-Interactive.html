Rhythm / Expressive 互动实验室
CLICK · DRAG · REVERSE · INTERRUPT

这次，直接点。
拖动、形变、暂停、再继续。

依据已读到的 Rhythm 固定版本源码行为，做成可操作的浏览器重建。没有退回普通直线进度条；不需要网络、安装或编译。

真实性边界：这是独立编写的 Canvas / JavaScript 互动重建，不是官方 Web 控件，也不是 Compose 在浏览器里运行。播放形变、旋转、按压等来自已核验行为；九瓣轮廓、波形、弹簧求解与部分演示时长是浏览器近似。每个区域标明来源等级，不能当作原生效果已验收。

来源：WaveSlider.kt 的轨道实际调用官方 LinearWavyProgressIndicator，手柄与拖动由作者扩展。近似：本页用正弦线展示机制，波长40px、波速20px/s、振幅5px均为Web展示值，不是官方默认。
操作方式与参数边界

为什么标成草图

原报告记录 ExpressivePlayerControlGroup 的 weight 与圆角联动，本轮核验的是另一个 ExpressiveButtonGroup 文件。此处用报告作为方向做独立交互草图，弹簧与数值组织不当作固定版本源码结论。这样可以先直观检查喜好，再决定是否追踪实际调用。

怎么读这个页面

现在可以：检查交互方向、按压/反向的感觉、波浪收放、手柄变化、选择层级。
现在不能：验收原生MotionScheme、MaterialShapes路径、Android触觉、Compose帧率和平台语义。
原生实录：当前没有，不放伪视频。浏览器Canvas重建不是Compose运行器，也不是Google官方组件分发。
