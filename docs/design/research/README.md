## 证据等级（沿用索引里的四档）

- **SOURCE**：在固定 SHA 读到实现。本文档区的多数结论属于这一档，但"读到某几行"不等于"通读整文件"，具体范围写在 `rhythm-list-items-06.md` §0。
- **REPORT**：解包报告提供的线索，未源核验的数值不得当事实。
- **WEB-REBUILD**：浏览器重建，不是 Compose，也不是官方精确几何。
- **NATIVE-TEST**：需要编译、指定模拟器或真机、有运行记录。**本目录所有批次都没有这一档。**

## 三条边界

1. **没有运行。** 从头到尾没有编译 Rhythm、没有安装、没有在模拟器或真机上跑过一次。所有"动效看起来如何"的话都不成立。
2. **源码与二进制不逐项对齐。** R8 会内联与合并类，调用点数量不能反推源码次数；反过来，源码里有 34 处 `Slider(` 不代表二进制有 34 个调用点（实际只剩 1 个）。
3. **原型不是证据。** 网页里的数值（例如曾被写进原型讨论的 1.025 抬升）是重建时选的观感值，不是 Rhythm 的常量；该值在三份现存 HTML 中已检索不到，故一律作废。行缩放以源码 1.005 / 0.98 / 1 为准。
