## 更多按钮（32×44，不是 48×48）

- 按压高亮与 idle 帧逐像素差分，唯一的差异区域：`x 880–963`、`y 960–1075` → **84 × 116 px = 32.0 × 44.2 dp**，中心 `(921.5, 1017.5)`。
- 为对照：`uiautomator` 对该按钮报 `[859,638][985,764]` = 126×126 = 48dp —— 平台最小触控目标膨胀，**不是**布局盒。
- 右缘：`963.5px`；滚动条命中区（40dp 宽、右留白 4dp）左缘：`1080 − 10.5 − 105 = 964.5px` → 两者相邻不重叠。
